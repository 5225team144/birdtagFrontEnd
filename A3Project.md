BirdTag: An AWS-powered Serverless Media Storage System with Advanced Tagging Capabilities

Group: 144
Team Member:

Tech Stack:
AWS
- AWS cognito
- AWS S3
- AWS lambda
- AWS Dynamo DB
- AWS API Gateway
- AWS SNS

Frontend
- vanilla html, css, js

Functionality:
- Cognito Authentication
- Upload files (images, videos, audios)
- Find images and videos based on the tags
- Find files based on bird species
- Find files based on the thumbnail’s URL
- Find files based on the tags of a file
- Manual addition or removal of tags with bulk tagging
- Delete files

Lambda Function:
File Handling
- Building Images Thumbnails
- Tagging Files

Queries
- search by tags
- search by bird species
- search by thumbnail's URL
- search by uploading files with same tags
- bulk tag addition or removal
- delete files
